# 🧠 1. RELASI INTI (ALUR RESEP OBAT)

## 🔵 MASTER RESEP

### `resep_obat (ro)`

Ini tabel **header resep**

Relasi:

* `ro.no_rawat` → `reg_periksa.no_rawat`
* `ro.kd_dokter` → `dokter.kd_dokter`

---

## 🟡 REGISTRASI PASIEN

### `reg_periksa (rp)`

* sumber pasien rawat jalan / inap

Relasi:

* `rp.no_rkm_medis` → `pasien.no_rkm_medis`

---

## 🟢 PASIEN

### `pasien (ps)`

* identitas pasien

---

## 🔵 DETAIL OBAT NON RACIKAN

### `detail_pemberian_obat (dpo)`

Ini isi obat langsung (bukan racikan)

Relasi:

* `dpo.no_rawat` → `resep_obat.no_rawat`
* `dpo.kode_brng` → `databarang.kode_brng`

---

## 🟣 ATURAN PAKAI

### `aturan_pakai (ap)`

* aturan tiap obat

Relasi:

* `ap.no_rawat`
* `ap.kode_brng`

---

## 🔴 RACIKAN HEADER

### `obat_racikan (or)`

* 1 resep bisa punya banyak racikan

Relasi:

* `or.no_resep` (logikanya sama group resep)
* `or.no_rawat`

---

## 🟠 RACIKAN DETAIL

### `detail_obat_racikan (dor)`

* isi bahan racikan

Relasi:

* `dor.no_racik`
* `dor.kode_brng`
* `dor.no_rawat`

---

## 🟤 MASTER OBAT

### `databarang (db)`

* nama obat + harga

---

## 🧑‍⚕️ DOKTER

### `dokter (dk)`

* pembuat resep

---

## 🏥 RAWAT INAP (opsional filter)

### `kamar_inap`

* untuk menentukan range tanggal

# 🔥 2. ALUR DATA (SIMPLE)

```
resep_obat (HEADER)
    │
    ├── reg_periksa → pasien
    ├── dokter
    │
    ├── detail_pemberian_obat (NON RACIK)
    │       └── aturan_pakai
    │
    └── obat_racikan (HEADER RACIK)
            └── detail_obat_racikan
                    └── databarang
```

# 🧾 3. QUERY FULL (VERSI FINAL CLEAN LARAVEL)

## 🔵 HEADER RESEP

```php
$resep = DB::table('resep_obat as ro')
    ->join('reg_periksa as rp', 'rp.no_rawat', '=', 'ro.no_rawat')
    ->join('pasien as ps', 'ps.no_rkm_medis', '=', 'rp.no_rkm_medis')
    ->join('dokter as dk', 'dk.kd_dokter', '=', 'ro.kd_dokter')
    ->where('ro.no_rawat', $no_rawat)
    ->select(
        'ro.no_resep',
        'ro.no_rawat',
        'ro.tgl_perawatan',
        'ro.jam',
        'ro.kd_dokter',
        'ps.no_rkm_medis',
        'ps.nm_pasien',
        'dk.nm_dokter'
    )
    ->orderBy('ro.tgl_perawatan')
    ->orderBy('ro.jam')
    ->get();
```

$data = DB::table('resep_obat as ro')
    ->join('reg_periksa as rp', 'rp.no_rawat', '=', 'ro.no_rawat')
    ->join('pasien as ps', 'ps.no_rkm_medis', '=', 'rp.no_rkm_medis')

    // NON RACIKAN

             ->on('dpo.jam', '=', 'ro.jam');
    })

    ->leftJoin('databarang as db', 'db.kode_brng', '=', 'dpo.kode_brng')

    // ATURAN PAKAI
    ->leftJoin('aturan_pakai as ap', function ($join) {
        $join->on('ap.no_rawat', '=', 'dpo.no_rawat')
             ->on('ap.tgl_perawatan', '=', 'dpo.tgl_perawatan')
             ->on('ap.jam', '=', 'dpo.jam')
             ->on('ap.kode_brng', '=', 'dpo.kode_brng');
    })

    // RACIKAN HEADER
    ->leftJoin('obat_racikan as orc', function ($join) {
        $join->on('orc.no_rawat', '=', 'ro.no_rawat')
             ->on('orc.tgl_perawatan', '=', 'ro.tgl_perawatan')
             ->on('orc.jam', '=', 'ro.jam');
    })

    ->leftJoin('metode_racik as mr', 'mr.kd_racik', '=', 'orc.kd_racik')

    // RACIKAN DETAIL
    ->leftJoin('detail_obat_racikan as dor', function ($join) {
        $join->on('dor.no_rawat', '=', 'orc.no_rawat')

             ->on('dor.jam', '=', 'orc.jam')
             ->on('dor.no_racik', '=', 'orc.no_racik');
    })

    ->leftJoin('databarang as db2', 'db2.kode_brng', '=', 'dor.kode_brng')
